How this model works

This is a synthetic mine operations simulation using the North Pit OpenMines equipment configuration. Fuel rates, travel variation, equipment outages and operational events are modeled assumptions, not measured field telemetry.

All charts in the working prototype are calculated from OreFlow API results. A recorded snapshot can be used when no API is connected; results in that mode are clearly labeled.
